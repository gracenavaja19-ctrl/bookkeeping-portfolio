# Bookkeeping Portfolio Website

A simple, mobile-friendly, black-and-white website for a bookkeeping business.
Built with plain HTML, CSS, and JavaScript. No build step, no secrets, no paid services.

## Files
- `index.html` – page content
- `styles.css` – design and layout
- `script.js` – mobile menu and footer year
- `favicon.svg` – browser tab icon

## Edit your content
Search `index.html` for `Your Name`, `[` brackets, and `you@example.com` and replace them with your own details.

## Test locally
Double-click `index.html` to open it in your browser.

## Deploy
Hosted on Cloudflare Pages: framework preset **None**, build command **empty**, output directory **/**.
